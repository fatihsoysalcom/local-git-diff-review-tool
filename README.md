# Local Git Diff Review Tool

This Python script provides a basic local code review tool. It generates a diff of staged Git changes and prints it to the console, simulating a pre-push review process for a colleague.

## Language

`python`

## How to Run

1. Ensure Git is installed and you are in a Git repository.
2. Stage some changes using `git add <files>`.
3. Run the script: `python diff_review.py`
